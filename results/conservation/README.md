# 🧬 Conservation Results

> **Residue-level evolutionary conservation of TP53 across the curated mammalian sequence dataset.**

This directory documents the conservation-analysis component of the project.

The conservation analysis asks:

> **Which TP53 residues are most strongly constrained across the analyzed mammalian sequences, and how does this conservation relate to recurrent human cancer-associated hotspot positions?**
