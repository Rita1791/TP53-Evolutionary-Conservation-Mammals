# 🌳 Phylogenetic Results

> **Evolutionary relationships inferred from the curated mammalian TP53 sequence dataset.**

This directory contains the machine-readable phylogenetic outputs generated during the comparative analysis.

---

## 🧬 Purpose

Phylogenetic reconstruction provides evolutionary context for the analyzed TP53 sequences.

The objective is not to use phylogeny as a substitute for residue-level conservation analysis, but to provide an independent evolutionary framework within which sequence relationships can be evaluated.
