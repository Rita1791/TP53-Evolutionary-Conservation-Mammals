# 📊 Statistical Results

> **Statistical evaluation of evolutionary conservation at recurrent human TP53 cancer-associated hotspot residues.**

This directory contains the statistical outputs generated to evaluate whether the observed hotspot conservation pattern is stronger than expected under an appropriate null model.

---

## 🎯 Statistical Question

> **Are recurrent human TP53 cancer-associated hotspot residues more evolutionarily conserved than expected under matched background sampling?**

The statistical framework complements the descriptive conservation analysis.
