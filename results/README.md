# 📊 Results

> **Derived computational outputs from the comparative evolutionary analysis of TP53 across mammals.**

This directory contains the principal computational outputs generated from the curated TP53 sequence dataset, cancer-associated hotspot definitions, statistical analyses, and phylogenetic reconstruction.

The results are organized by analytical function so that each observation can be traced back to the corresponding computational workflow.
