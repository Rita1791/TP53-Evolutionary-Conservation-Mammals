# 📎 Supplementary Figures

> **Extended visual evidence supporting the methodological, statistical, phylogenetic, structural, and sensitivity analyses of the TP53 study.**

This directory contains supplementary figures that extend and validate the primary findings presented in [`../main/`](../main/).

The purpose of these figures is to allow researchers to inspect the analytical evidence in greater depth without overcrowding the primary scientific narrative.

---

## 🔬 Purpose

Supplementary figures may provide additional evidence relating to:

- 🧬 sequence alignment;
- 📊 residue-level conservation;
- ⚖️ hotspot/control distributions;
- 📈 statistical analysis;
- 🔄 permutation testing;
- 🌳 phylogenetic reconstruction;
- 🔍 phylogenetic sensitivity;
- 🧩 structural context;
- 🧪 quality-control analyses;
- and exploratory computational analyses.

---
