# 📊 Figures

> **Publication-ready visual outputs supporting the comparative evolutionary analysis of TP53 mutation hotspots across mammalian species.**

This directory contains the finalized figures generated from the computational analyses in this repository.

The figures are organized into two categories:

- **`main/`** — primary figures directly supporting the central research question and conclusions.
- **`supplementary/`** — additional figures providing methodological, statistical, phylogenetic, or exploratory detail.
