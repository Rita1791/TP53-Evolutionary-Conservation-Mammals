# ⭐ Main Figures

> **Primary visual evidence supporting the central findings of the TP53 evolutionary-conservation study.**

This directory contains the principal figures generated from the computational analyses of evolutionary conservation and recurrent human TP53 cancer-associated mutation hotspots across mammals.

The figures presented here represent the **core visual evidence** of the study and are intended for manuscript preparation, conference presentation, and rapid scientific review.
