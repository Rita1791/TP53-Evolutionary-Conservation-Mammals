# ♻️ Reproducibility

> **A computational reproducibility framework connecting biological inputs, code, processed datasets, analyses, results, and scientific interpretation.**

---

# 🧭 1. Purpose

The repository is structured so that a researcher can follow the computational pathway from the original biological resources to the reported analytical outputs.

The reproducibility chain is:

```text
🌐 Source resources
      ↓
📥 Raw data
      ↓
🧹 Curation
      ↓
🧬 Processed data
      ↓
💻 Computational analysis
      ↓
📊 Statistical analysis
      ↓
📈 Results
      ↓
🖼️ Figures
      ↓
🧠 Interpretation
