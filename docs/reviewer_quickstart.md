# Reviewer Quickstart

## Purpose of This File

This file is designed for reviewers, professors, PhD supervisors, and computational biology researchers who want to understand the project quickly without reading the full repository first.

---

## Project in One Sentence

This project investigates whether recurrent human TP53 cancer mutation hotspots occur at amino-acid residues that are unusually conserved across mammalian evolution.

---

## Research Question

Do recurrently mutated human TP53 cancer hotspot residues overlap with positions under strong evolutionary constraint across mammals?

---

## Biological Context

TP53 encodes the p53 tumour-suppressor protein, a central regulator of genomic stability, DNA-damage response, cell-cycle control, apoptosis, and tumour suppression.
